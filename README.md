# MicroERP

Archivos principales:
- index.html       Landing page
- cliente.html     Vista Cliente: buscador, filtros y Productos Disponibles
- vendedor.html    Vista Vendedor: Búsqueda Rápida y Control de Inventario
- admin.html       Vista Administrador: Acciones, Editor de Producto y Tabla Editable
- figma-link.txt   Enlace a los wireframes
- js/microerp.js   Almacenamiento compartido y tema

IMPORTANTE:
- No hay productos precargados.
- El inventario inicia vacío.
- Si el administrador registra un producto, se guarda en localStorage y luego puede aparecer en Cliente y Vendedor.
- Las vistas están separadas por rol.
- Para acceder a las vistas de los roles, ingresar con correo y contraseña cualesquiera.
